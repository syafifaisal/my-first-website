# My First Website 🚀

Website pertama saya untuk belajar **HTML, CSS, JavaScript dan GitHub**. Projek ini dibuat dengan bantuan ChatGPT, kemudian dimuat naik terus ke repository GitHub.

## Apa yang ada?

- Landing page dengan tema gelap dan warna gradient.
- Layout responsif yang sesuai untuk laptop atau telefon.
- Butang interaktif yang mengira jumlah klik.
- Tiada akaun, kata laluan, API key atau library tambahan diperlukan.

## Kenali fail projek

| Fail | Fungsi |
| --- | --- |
| `index.html` | Struktur dan kandungan website |
| `style.css` | Warna, reka bentuk dan susun atur |
| `script.js` | Fungsi butang interaktif |
| `README.md` | Nota penerangan projek |

## Cara buka website

**Cara paling mudah:** Muat turun code dari butang **Code → Download ZIP** di GitHub, extract ZIP, kemudian double-click `index.html`.

**Cara GitHub Pages:** Pergi ke **Settings → Pages**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, kemudian klik **Save**. Selepas GitHub Pages berjaya menerbitkan laman, URL biasanya:

https://syafifaisal.github.io/my-first-website/

(Pautan ini hanya akan berfungsi selepas GitHub Pages diaktifkan dan deployment berjaya.)

## Bagaimana GitHub bekerja?

```text
Edit code → Save file → Commit → Push → GitHub
```

- **Repository:** Folder projek di GitHub.
- **Commit:** Rekod perubahan dalam sejarah projek.
- **Push:** Hantar commit dari komputer ke GitHub.
- **Pull:** Ambil perubahan terbaru dari GitHub ke komputer.
- **Branch:** Laluan kerja berasingan untuk mencuba perubahan.

### Cuba ubah sesuatu

1. Buka fail `index.html` dalam GitHub.
2. Klik ikon pensel (**Edit this file**).
3. Cari `Ini website` dan tukar teks kepada ayat kegemaran anda.
4. Tekan **Commit changes**.
5. Jika GitHub Pages sudah diaktifkan, perubahan akan diterbitkan semula selepas deployment.

## Keselamatan

Ini laman statik tanpa login atau backend. Jangan masukkan password, token, API key, atau maklumat peribadi ke dalam fail yang akan di-commit ke repository public.

Dibina untuk belajar secara praktikal, satu langkah demi satu langkah.
